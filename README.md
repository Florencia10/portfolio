# Built by Flor · Made to scale

Source of florenciadiezdimauro.com, the public portfolio of Florencia Diez Di Mauro.

- `index.html`: the whole site (self-contained; content lives in the arrays inside its `<script>`).
- Netlify publishes this repository automatically on every push to `main`. No build step.

## What can live here
This repository is public. `.gitignore` works as an allowlist: only `index.html`, `README.md`, `netlify.toml` and `.gitignore` can be committed. Anything private (hub, finances, project files) lives elsewhere.
